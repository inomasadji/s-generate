# Экспорт

Два формата, оба без библиотек: PNG — средствами браузера, GIF — своим энкодером.
Экспорт всегда идёт из того же `Scene`, что и превью: никаких «отдельных настроек
для сохранения».

## Общие правила

* Рендер — в offscreen-canvas, без UI и курсоров.
* Масштаб — целый множитель (`1×, 2×, 3×, 4×`); размеры пресетами:
  `1080×1080`, `1600×1200`, `1200×1600`, `2048×2048`.
* Имя файла: `s-generate_<kind>_<slug>_<seed>.png`, где `slug` — латинское имя
  объекта в нижнем регистре через дефис, `seed` — до 12 символов.
* Рядом можно скачать `.json` с описанием сцены — это честнее EXIF и позволяет
  восстановить кадр.

## PNG

```js
const blob = await canvas.convertToBlob({ type: 'image/png' }); // OffscreenCanvas
// или
const blob = await new Promise((r) => canvas.toBlob(r, 'image/png'));
```

* PNG сжимает без потерь; при 2×–4× картинка остаётся резкой.
* Альфа не нужна: фон всегда непрозрачный (бумага, небо).
* Дизеринг зерна уже в кадре — дополнительное квантование для PNG не делаем.
* Проверка в тесте: сигнатура `89 50 4E 47`, размер > 1 КБ, `width/height` из IHDR
  совпадают с пресетом.

## GIF

GIF — 8-битный формат с палитрой и LZW. Пишем энкодер сами: это ~300 строк, зато
никаких зависимостей и полный контроль над качеством.

### Структура файла

```
"GIF89a"
Logical Screen Descriptor   — ширина, высота, флаг GCT, размер палитры
Global Color Table          — 2^n цветов по 3 байта
[Netscape Application Extension] — цикл: "NETSCAPE2.0", loop = 0 (бесконечно)
для каждого кадра:
  Graphic Control Extension — задержка (1/100 с), disposal method = 1
  Image Descriptor          — позиция 0,0, размер кадра, флаг LCT
  [Local Color Table]
  LZW-данные                — min code size 8, затем подблоки ≤ 255 байт, 0x00
";"                         — трейлер
```

### Палитра

* Квантование — median cut до 255 цветов, 256-й резервируется под фон (или не
  используется).
* Глобальная палитра, если кадры близки по цвету (обычный случай). Локальная —
  только если сцена меняет освещение (день → ночь).
* Дизеринг: Floyd–Steinberg с ошибкой, распространяемой на 7/16 соседей. Включать
  при ≤ 64 цветах, иначе видны «змеи».
* Проверка: палитра не должна «плыть» между кадрами, иначе мерцание.

### Тайминг

* Задержка в сотых долях секунды, минимум `2` (20 мс), обычно `8` (12,5 fps).
* Кадры — по равномерной сетке `t = i · dt`, независимо от реального времени.
* Цикл бесконечный (`loop = 0`), закрывающий кадр не нужен: сцена зациклена по
  ветру, а не по сюжету.

### Бюджеты

| Параметр | Значение |
|---|---|
| Размер кадра | 480×270 (или 360×360 для плашки) |
| Кадров | 24–48 |
| Цветов | 64–128 |
| FPS | 10–15 |
| Вес файла | ≤ 5 МБ |

Если не влезает — сначала уменьшать число кадров, потом палитру, потом размер.

### Где считать

* Основной путь — `OffscreenCanvas` + `Worker`: главный поток не блокируется.
* Фолбэк — обычный canvas в основном потоке, с `await new Promise(r => setTimeout(r))`
  раз в несколько кадров, чтобы UI не замирал.
* `ImageData` кадра → квантование → LZW → `Uint8Array` → `Blob('image/gif')`.

### Тесты

* Фиксированный кадр 8×8 с известной палитрой → побайтовый хэш GIF.
* Проверка заголовка, числа кадров, задержек и наличия `NETSCAPE2.0`.
* Проверка, что два прогона с одним сидом дают идентичные байты.

## Что не делаем

* APNG и WebP-анимацию — пока не нужно.
* Видео (MP4/WebM) — вне формата «картинка из кода».
* Серверный рендер и очереди — всё на клиенте.
