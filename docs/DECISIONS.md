# Журнал решений

Одно решение — одна строка. Если решение меняется, старая запись не удаляется, а
помечается `заменено D-0xx`. Правила репозитория — в [AGENTS.md](../AGENTS.md).

| ID | Дата | Решение | Почему | Альтернативы |
|---|---|---|---|---|
| D-001 | 2026-11-16 | Рендер только Canvas 2D | Проще, детерминированнее, пиксели легко проверить и экспортировать; 3D имитируется сортировкой полигонов | WebGL, three.js, WebGPU |
| D-002 | 2026-11-16 | Ноль зависимостей, нативные ES-модули, без сборки | Проект учебный: весь код виден и работает «как есть»; GitHub Pages не требует CI | bundler + npm-пакеты |
| D-003 | 2026-11-16 | Детерминизм: строка → `hashSeed` → mulberry32, именованные потоки | Нужны воспроизводимые кадры, golden-тесты и ссылки с сидом | `Math.random()`, как в статье |
| D-004 | 2026-11-16 | Display list как граница между «формой» и «пикселями» | Чистая часть тестируется в Node без canvas; растеризация остаётся тонкой | рендер сразу в canvas |
| D-005 | 2026-11-16 | Ортографическая камера | Картинка не зависит от размера холста; плашка и сцена — один код | перспектива |
| D-006 | 2026-11-16 | Painter's algorithm вместо Z-буфера | Z-буфер в 2D всё равно надо эмулировать; сортировка даёт нужный стиль | собственный растеризатор с z |
| D-007 | 2026-11-16 | Объёмные полигоны для грибов, билборды для листвы и облаков | Гриб без объёма не читается; листва — наоборот, дешевле плоскими кластерами | всё в 3D; всё билбордами |
| D-008 | 2026-11-16 | Стиль — гладкая иллюстрация, квантованный свет, чернильный контур, зерно | Похоже на ботанический рисунок; стабильно хэшируется | пиксель-арт, реализм |
| D-009 | 2026-11-16 | Плашка и сцена — две композиции одной модели | Один генератор, два вывода; не нужен отдельный код для карточки | отдельные приложения |
| D-010 | 2026-11-16 | Имена из слогов (JSON), цепь Маркова — опционально | Данных на 2 КБ, нет внешнего токенизатора, читаемость контролируема | BPE + матрица переходов |
| D-011 | 2026-11-16 | PNG через `canvas.toBlob`, GIF — свой энкодер | PNG бесплатно; GIF-библиотека нарушила бы D-002 | gif.js и подобные |
| D-012 | 2026-11-16 | Документация по-русски, идентификаторы по-английски | Тексты для себя и читателя, код — по общей практике | всё по-русски |
| D-013 | 2026-11-16 | Своя палитра ≤ 24 тонов на сцену | Цвет — часть стиля, а не случайность; проще согласовать слои | случайные цвета |
| D-014 | 2026-11-16 | Node только для тестов и статического сервера | `node --test` и `node:http` покрывают всё; `npm install` не нужен | Vite, ESLint, Prettier |
| D-015 | 2026-11-16 | Код — MIT, сгенерированные изображения — CC0 | MIT самый простой и разрешительный, не мешает ни учёбе, ни переиспользованию; картинки — общественное достояние, чтобы их можно было брать без вопросов | Apache-2.0, GPL-3.0, CC BY 4.0, без лицензии |
| D-016 | 2026-11-16 | Пиксель-арт отложен до M8 | Сначала довести иллюстрацию; профиль вывода позволит добавить стиль позже без переделки мира | пиксель-арт сразу |
| D-017 | 2026-11-16 | Агент сам коммитит, пушит, мёрджит и ведёт issues | Пользователь делегировал рутину; деструктивные операции остаются за подтверждением | подтверждать каждый шаг |
| D-018 | 2026-11-16 | Контур слоя рисуется до заливки и вдвое толще | Заливка сама скрывает внутренние рёбра; иначе дальний край шляпки просвечивает сквозь объект | полноценный z-буфер, маска видимости |
| D-019 | 2026-11-16 | Листва и облака — плоские диски, а не сферы | При малом наклоне камеры разницы не видно, полигонов в разы меньше | сферы, реальные билборды |
| D-020 | 2026-11-16 | Слой объекта = `10 + index * 10`, внутри — подслои | Дальний объект рисуется целиком до ближнего, а подслои не конфликтуют | глобальная сортировка всех полигонов по z |
| D-021 | 2026-11-16 | Горы — два плоских хребта, без фасеток | Треугольные грани выглядели наклейками; глубину дают дальний светлый план и снег | фасеточное затенение |
| D-022 | 2026-11-17 | У каждого рода своя школа имён | Гриб и дерево — ботаника, гора — кельтская, холм — славянская, облако — «азиатская»: жанр читается до подписи | одна латынь для всего |
| D-023 | 2026-11-17 | Широкие плашки получают небо внутри рамки | Гора и холм в пустом прямоугольнике висят; небо делает из них «вид» | оставить бумагу |
| D-024 | 2026-11-17 | Широкие плашки выравниваются по низу области | Силуэт стоит на земле, а не в центре листа | центрирование по обеим осям |
| D-025 | 2026-11-17 | Крона — оболочка-эллипсоид плюс кластеры на ветках | «Шарики на палке» не читаются как дерево; оболочка держит силуэт, кластеры дают фактуру | только кластеры на концах веток |
| D-026 | 2026-11-17 | Нормаль листового диска наклонена к центру кроны | Верх и левый бок светлее, низ и правый темнее: крона получает объём без градиентов | плоский цвет на весь диск |
| D-027 | 2026-11-17 | Сезон дерева выводится из палитры | Не нужен отдельный переключатель: осень уже задана темой, alpine — зимняя | параметр `season` в UI |
| D-028 | 2026-11-17 | Листва — неровные многоугольники с отдельными листиками, кора — по шуму | Ровные диски и однотонный ствол выглядели пластиком | текстуры-картинки |
| D-029 | 2026-11-17 | Горы: асимметричные пики, седловины, скальные полосы | Ровные треугольники читались как декорация; асимметрия и скалы дают суровость | фасеточное затенение |
| D-030 | 2026-11-17 | Снег языками ниже снеговой линии | Ровная шапка выглядела палаткой; языки читаются как снежники | градиент по вершине |
| D-031 | 2026-11-17 | Дымка у подножия полупрозрачными полосами | Гора «стоит на линейке»; мгла отделяет её от земли | жёсткая линия горизонта |
| D-032 | 2026-11-17 | Новый сид — `nextSeed(seed)` из хэша предыдущего, а не `Math.random()` | Кнопка «ещё» не нарушает D-003: серия вариантов из одного адреса воспроизводима, тестируема и даёт короткие сиды в URL | `Math.random()`, `Date.now()`, счётчик `?n=1,2,3` |
| D-033 | 2026-11-17 | «Случайно» бросает род, палитру, форму и характер из `rngStream(nextSeed(seed), 'dice')` | Соблазн взять `Math.random()` сломал бы D-003; бросок из сида воспроизводится по URL и проверяется тестом. Режим не крутится: в сцене род и характер не видны | `Math.random()`, случайный режим, отдельный счётчик бросков |
| D-034 | 2026-11-17 | Девять палитр, включая тёмную `night` и монохромную `ink` | Пять тем быстро приедаются; тёмная тема проверяет, что `ink` — это контраст, а не «тёмный цвет»: в `night` он светлее бумаги | оставить пять тем, перекрашивать тона в рантайме |
| D-035 | 2026-11-17 | Кадр трубы переносится с предыдущего кольца (parallel transport) | Кадр от `[0,1,0]` перескакивал на 90° при изгибе круче ~80°, кольца перекручивались, и ствол у камня выглядел разломленным | фиксированный «верх» трубы, больше колец |
| D-036 | 2026-11-17 | Вершины гор неравные, снег ищется на кромке хребта | Одинаковые пики и шапка, построенная от собственной ширины, давали частокол и белые треугольники в воздухе | сглаживать силуэт, рисовать снег прямоугольником |
| D-037 | 2026-11-17 | Холм: купол, фасеты по склонам, кромка, нижняя тень, второе дерево | Три ровные полосы читались как стена; фасеты дают объём тем же квантованным светом, что и у объектов | градиент по форме (запрещён), текстура-картинка |
| D-038 | 2026-11-17 | Облако: три тона и светлая кромка сверху | Два пятна — тело и тень — выглядели плоской наклейкой; кромка повторяет верхнюю дугу пуфа, а не рисует круглый блик | градиент, отдельная текстура |
| D-039 | 2026-11-17 | Хвойные трёх типов, лиственные — с узлами листьев | «Ёлка» была одна на все сиды, а листва — ровные блины. Тип выбирается сидом, листья идут отдельным потоком `seed:leaves`, чтобы правка листвы не сдвигала ветки | один тип хвойных, листья тем же потоком |
| D-040 | 2026-11-17 | Хребет гор — фасеты по наклону грани | Плоская заливка не давала теней на вершинах; фасеты используют тот же квантованный свет, что и остальные объекты | градиент по горе, тени-наклейки |
| D-041 | 2026-11-17 | Трава холма — пучки, разбросанные шумом | Ряд одиночных травинок вдоль гребня читался как пунктир; пучки по гребню и склону дают шумную фактуру | газон из одинаковых травинок |
