# Каталог родов

Здесь описано, **что** генерируется и **какими параметрами** управляется. Точные
формулы живут в коде, здесь — анатомия и смысл параметров.

## Общий конвейер

Все объёмные объекты собираются одинаково:

1. **Профиль.** Кривая Катмулла-Рома по 4–7 ключевым точкам. Для ножки это ось, для
   шляпки — сечение вращения, для горы — хребет.
2. **Каркас.** Профиль либо сдвигается (**sweep**), либо вращается (**revolve**).
   На каждом шаге рождается замкнутый контур из `segments` точек.
3. **Грани.** Квады между соседними контурами → 2 треугольника. Индексы идут в
   фиксированном порядке — от этого зависит стабильная сортировка.
4. **Шум.** Три независимых слоя поверх базовой формы:
   * *радиальный* — двигает точку вдоль радиуса;
   * *угловой* — искажает угол;
   * *ортогональный* — двигает точку вдоль нормали к профилю.
   Амплитуда каждого — функция `(a, t)`, чаще всего затухающая к основанию.
5. **Цвет.** Функция `(a, t)` плюс квантованный свет. Никаких UV и текстур.
6. **Детали.** Облако точек → выпуклая оболочка (2D, обход Эндрю) → полигон.

Шум всегда сэмплится в непрерывном домене, иначе форма «рвётся» на швах.

## Гриб

Эталонный род: на нём отлаживается весь движок.

### Анатомия

| Часть | Геометрия | Что варьируется |
|---|---|---|
| Ножка (stipe) | sweep профиля; сечение — замкнутый сплайн из 4 точек с радиусом `r(a, t)` | высота, толщина, наклон, изгиб, «лохматость» у земли |
| Шляпка (pileus) | revolve профиля `(r, y)` вокруг оси ножки | радиус, выпуклость, форма края (вниз/вверх), толщина |
| Пластинки (gills) | радиальные тонкие пластины под шляпкой | число (12–40), глубина |
| Юбка (annulus) | малое кольцо у верха ножки | есть/нет, ширина |
| Точки | облако точек на поверхности → выпуклая оболочка | число (0–24), радиус, только у «мухоморов» |

### Параметры

| Параметр | Сейчас | Влияние |
|---|---|---|
| `height` | 0.95–1.45 | общий рост |
| `stemRadius` | 0.06–0.11 | толщина ножки |
| `stemLean` | −0.22–0.2 | наклон верхушки |
| `stemNoise` | 0.05–0.14 | рябь у основания, кверху затухает |
| `capRadius` | 0.55–0.95 | ширина шляпки |
| `capProfile` | `convex｜flat｜umbonate｜funnel` | силуэт шляпки |
| `capFlare` | задаётся профилем | отгиб края |
| `radialNoise` | 0.1–0.24 | рёбра и складки по краю |
| `angularNoise` | 0.02–0.09 | «кривизна» долей шляпки |
| `orthNoise` | 0.04–0.12 | бугры и вмятины на поверхности |
| `spotCount` | 0–12 | количество пятен |
| `ring` | план | юбка |
| `gills` | план | пластинки |

### Крайние формы

Чтобы грибы не были «одного лица», генератор обязан иногда выходить в крайности:

* высокая тонкая поганка с плоской шляпкой;
* приземистый боровик с толстой ножкой и выпуклой шляпкой;
* «мухомор» — красная шляпка, белые точки, юбка;
* трутовик — шляпка почти без ножки, растёт сбоку.

## Дерево

Набросок: уточняется при реализации (M3).

| Часть | Геометрия |
|---|---|
| Ствол | sweep, сужение `r(t) = r0 · (1 − t)^k` |
| Ветки | рекурсия: 2–4 ветки на узел, угол 20–50°, длина 0.5–0.75 от родителя |
| Листва | билборд-кластеры из 5–9 кругов в концах веток; для хвойных — ярусы |

| Параметр | Диапазон | Влияние |
|---|---|---|
| `height` | 1–3 | рост |
| `trunkRadius` | 0.04–0.16 | толщина |
| `branchDepth` | 2–4 | глубина рекурсии |
| `branchAngle` | 20–50° | «раскидистость» |
| `foliage` | `round｜conical｜sparse` | силуэт кроны |
| `foliageDensity` | 0.3–1 | плотность кластеров |

## Кустарник

3–9 стволов из одной точки, высота 0.2–0.5 от дерева, крона плотная и низкая.
Отличается от дерева не кодом, а параметрами: `branchDepth = 1–2`, короткий ствол,
широкий разброс.

## Холм

Силуэт — 1D-fBm по `x` с затуханием к краям. Три плана: дальний (высокий `haze`),
средний, ближний. Отдельных полигонов мало: важнее линия горизонта и цвет.

| Параметр | Влияние |
|---|---|
| `height` | амплитуда |
| `roughness` | число октав и «каменистость» |
| `width` | протяжённость |
| `haze` | смешение с цветом неба |

## Гора

Хребет — ломаная с 3–7 пиками, у каждого свой наклон. Тело — полигоны с фасетками:
нормаль грани даёт разный оттенок, поэтому гора читается как объём. Снеговая линия —
порог по `y`: выше него цвет смещается к белому.

## Облако

Объединение 5–12 кругов, обрезанных снизу горизонтальной линией (плоское основание).
Два тона: тело и тень снизу. Двигается медленно (анимация — сдвиг по `x`).

## Сцена

| Слой | Что | Дальность |
|---|---|---|
| 1 | небо, солнце/луна | ∞ |
| 2 | дальние горы | 40–60 |
| 3 | облака | 30–50 |
| 4 | средние холмы | 20–30 |
| 5 | лес (деревья) | 8–20 |
| 6 | земля, трава | 2–8 |
| 7 | герой (крупный гриб/куст) | 0–2 |
| 8 | передний план (размытые травинки) | < 0 |

Правила композиции:

* линия горизонта — 52–58 % высоты;
* «герой» — в одной из третей, не в центре;
* дальние слои светлее и холоднее (воздушная перспектива);
* на одной сцене один источник света.

## Палитры

| Тема | Настроение | Основа |
|---|---|---|
| `paper` | ботаническая иллюстрация | тёплая бумага, сепия, чернила |
| `forest` | летний лес | зелёные, кора, мох |
| `dusk` | сумерки | синие, розовые, фиолетовые |
| `alpine` | горы | серо-синие, снег, хвоя |
| `night` | ночь | тёмно-синие, лунный свет |
| `autumn` | осень | охра, ржавчина, бордо |

Тема задаёт ≤ 24 тона; каждый генератор берёт индексы из темы, а не hex-литералы.
