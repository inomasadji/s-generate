# Ресёрч: генеративные грибы

Источник: Илья Беликов (ferluht), **«Рисуем генеративные грибы на javascript»**,
Хабр, 13 февраля 2022.
<https://habr.com/ru/articles/651267/> — продолжение серии про генарт и NFT.

Статья описывает генератор 3D-грибов на three.js + WebGL, сделанный для минта на
fxhash. Ниже — выжимка техник и выводы для `s-generate`, который рисует то же самое
в Canvas 2D.

## Главная идея

Вся органика получается из одного приёма:

```
P(a, t) = базовая_поверхность(a, t) + шум(a, t) · масштаб(t)
цвет   = палитра(a, t) · свет(нормаль)
```

`a` — угол вокруг оси, `t` — положение вдоль профиля. И форма, и цвет, и шум — это
функции одних и тех же двух параметров. Ни UV, ни текстур, ни скелета.

## Ножка

* Ось — сплайн Катмулла-Рома по 4–5 точкам с джиттером по `x/z`.
* Сечение — **замкнутый** сплайн из 4 точек, радиус задаётся функцией `r(a, t)`.
  При `tension = 0.75` это не окружность, а скруглённый квадрат — отсюда «живое»
  сечение.
* Точки контура прикладываются к оси; квады индексируются вручную:
  `i * (rSegments + 1) + j` и соседи.
* Шум радиуса: `r = base + (1 − t) · (1 + rand()) · noise_c`. Амплитуда падает с
  высотой — низ лохматый, верх гладкий.

Формула сегмента Катмулла-Рома (`p0..p3` — соседние точки):

```
p(t) = 0.5 · ( 2p1
             + (−p0 + p2) · t
             + (2p0 − 5p1 + 4p2 − p3) · t²
             + (−p0 + 3p1 − 3p2 + p3) · t³ )
```

## Шляпка

Профиль `(r, y)` вращается вокруг оси. Точка поверхности:

```js
function pileus_surface(a0, t0) {
  const t = clamp(t0 * (1 + radnoise(a0, t0)), 0, 1);   // радиальный шум
  const p = shape.getPointAt(t);
  const tangent = shape.getTangentAt(t);
  const orth = cross([0, 0, 1], tangent);               // (−t.y, t.x, 0)
  const a = a0 + angnoise(a0, t0);                      // угловой шум
  const s = orthnoise(a0, t0);                          // ортогональный шум

  const out = [cos(a) * p.x, p.y, sin(a) * p.x];
  out[0] += orth[0] * cos(a) * s;
  out[1] += orth[1] * s;
  out[2] += orth[0] * sin(a) * s;
  return out;
}
```

Шум — 2D Перлин, сэмплится в домене `(t·cos a, t·sin a)`, то есть по единичному
диску. Домен выбран не случайно: он непрерывен по углу (при `a = 0` и `a = 2π`
значение одно и то же), поэтому нет шва.

| Слой | Формула в статье | Эффект |
|---|---|---|
| Радиальный | `−|noise| · 0.5` | только внутрь → рёбра и складки |
| Угловой | `noise · 0.2` | искривление долей |
| Ортогональный | `noise · t` | бугры, сильнее к краю |

## Детали

* **Точки на шляпке:** случайный центр `(a, t)` → облако из ~10 точек → выпуклая
  оболочка (`ConvexGeometry`) → все точки сливаются в одну геометрию.
* **Пластинки и юбка** — те же поверхности вращения с другим профилем.
* **Коллизии:** для каждого гриба строится упрощённая low-poly модель, пересечения
  проверяются по ней; размещение — rejection sampling.
* **Имена:** цепь Маркова на 200 BPE-токенах (YouTokenToMe), матрица переходов в
  JSON, в браузере — только выбор следующего токена.

## Стилизация

* Белый материал + **цвета вершин** вместо UV и текстур.
* `OutlineEffect` — расширение backface по нормалям, скетчевый контур.
* `EffectComposer` + шумовой пасс — «плёночное» зерно.

## Перенос на Canvas 2D

| В статье (WebGL) | У нас (Canvas 2D) |
|---|---|
| Z-буфер | painter's algorithm: стабильная сортировка полигонов по глубине |
| Шейдер освещения | цвет грани считается на CPU: `base · quantize(n · l)` |
| `OutlineEffect` | рёбра силуэта (встречаются один раз) → ломаные цветом `ink` |
| `ConvexGeometry` (3D) | выпуклая оболочка на плоскости (обход Эндрю, ~20 строк) |
| `mergeBufferGeometries` | `polys.push(...other.polys)` |
| Шумовой пасс | тайл `ImageData` 256×256 + `globalCompositeOperation: 'overlay'` |
| `THREE.CatmullRomCurve3` | свой сплайн в `core/spline.js` |
| `noisejs` | свой Перлин с таблицей из RNG (`core/noise.js`) |

## Что берём

* Параметризацию `(a, t)` для формы, шума и цвета — это ядро подхода.
* Sweep вместо `TubeGeometry`: сечение управляемо, форма органичнее.
* Три слоя шума с разными знаками и амплитудами.
* Вершинный цвет вместо UV: палитра задаётся аналитически.
* Детали как облака точек → оболочка.
* Скетчевый контур + зерно как «дешёвая» стилизация.

## Что меняем

* **Детерминизм.** В статье `Math.random()` повсюду, включая сид шума. У нас — сид,
  mulberry32 и именованные потоки; иначе нельзя ни сравнивать кадры, ни повторять.
* **Непрерывный шум на ножке.** `Math.random()` на вершину даёт «пух», а не форму.
  Берём Перлин и там.
* **Сечение ножки.** Горизонтальное сечение не даёт сильно изогнуть ножку. Если
  понадобится — переносить контур по кадру Френе.
* **Коллизии.** Не по вершинам, а по упрощённым силуэтам (эллипс/AABB), точная
  проверка — только для пересекающихся пар.
* **Имена.** Слоги вместо BPE-токенов: данных меньше, зависимостей нет, читаемость
  выше. Цепь Маркова — возможное улучшение, не необходимость.
* **Ортографическая камера** вместо перспективы: картинка не зависит от размера
  холста, плашка и сцена используют один код.
