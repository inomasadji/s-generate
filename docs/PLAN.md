# План

План не конечный. Это скорее направление: список того, что интересно сделать, и
порядок, в котором это дешевле делать. Раз в несколько этапов он переписывается —
это нормально и не требует извинений.

## Зачем

Сделать генератор, на который приятно смотреть: пятьдесят сидов подряд — и почти
каждый хочется сохранить. Попутно разобраться, как из нескольких сплайнов, шумов и
сортировки полигонов получается узнаваемый объём — без WebGL, движков и картинок.

Три вещи, которые считаются успехом:

1. **Узнаваемость.** Гриб похож на гриб, гора — на гору, даже в мелком масштабе.
2. **Разнообразие.** Соседние сиды заметно отличаются, но выглядят из одного мира.
3. **Воспроизводимость.** Сид из адресной строки через год даёт тот же кадр.

## Что делаем

| Объект | Режим | Приоритет |
|---|---|---|
| Гриб (ножка, шляпка, пластинки, юбка, точки) | плашка + сцена | 1 |
| Названия (латинские) | плашка | 2 |
| Дерево (ствол, ветки, листва) | плашка + сцена | 3 |
| Кустарник | сцена | 4 |
| Холм, гора | сцена | 5 |
| Облако, небо, атмосфера | сцена | 6 |
| Анимация (ветер, колыхание) | сцена | 7 |
| GIF-экспорт | сцена | 8 |

## Чего не делаем

* Никакого WebGL, three.js и шейдеров — это другой проект.
* Никаких фотореалистичных текстур, UV-развёрток и скелетной анимации.
* Никакого бэкенда, аккаунтов, NFT и блокчейна.
* Никакой «редактор сцены» с перетаскиванием мышью на первом этапе.
* Не гонимся за 60 fps в экспорте: экспорт может быть медленным, если картинка
  правильная.
* Пиксель-арт — не сейчас. Возможный второй стиль в дальней перспективе (M8).

## Этапы

### M0. Каркас

- [x] `AGENTS.md`, документация, статический сервер, `node --test`.
- [x] `index.html` с пустым canvas и `src/app/main.js`.
- [x] `core/rng.js` + тест детерминизма.
- [x] `core/math.js`, `core/spline.js` (Catmull-Rom), `core/noise.js` (Perlin/fBm).

**Готово, когда:** `npm start` открывает пустую сцену, `npm test` зелёный, один сид
даёт один и тот же набор чисел.

### M1. Гриб в плашке

- [x] Sweep ножки: профильный сплайн + замкнутое сечение с радиусом `r(a, t)`.
- [x] Revolve шляпки + три слоя шума (радиальный, угловой, ортогональный).
- [x] Заливка полигонов, квантованный свет, чернильный контур.
- [x] Рамка, подпись, сид, палитра.
- [x] Экспорт PNG.

**Готово, когда:** 20 сидов подряд дают 20 разных узнаваемых грибов, PNG
скачивается, golden-тест стабилен.

### M2. Имена и детали

- [x] Слоговый генератор латинских названий (JSON-подобные данные, без зависимостей).
- [x] Имена по родам: латынь, кельтская, славянская и «азиатская» школы.
- [x] Юбка на ножке и точки на шляпке (2D-оболочка облака точек).
- [ ] Пластинки — отложено: при взгляде сверху их не видно, нужен нижний ракурс.
- [x] Вариации палитр: `paper`, `forest`, `dusk`, `autumn`, `alpine`.

### M2b. Отдельные роды

- [x] `kind`: гриб, дерево, холм, гора, облако — у каждого своя плашка.
- [x] Школа имён под род: латынь, кельтская, славянская, «азиатская».
- [x] Широкие роды получают небо в рамке и выравнивание по низу.

### M3. Деревья и кустарники

- [x] Рекурсивное ветвление ствола (3–5 веток из верхней половины).
- [x] Листва как билборд-кластеры; лиственный и хвойный силуэты.
- [x] Кустарник как несколько стволов из одной точки.

### M4. Рельеф

- [x] Холмы: силуэт из 1D-fBm, три плана.
- [x] Горы: два хребта, снеговая линия, светлый дальний план.
- [x] Облака: объединение кругов, тень снизу.
- [x] Атмосферная перспектива и небо.

### M5. Сцена

- [x] Слои: небо → дальние горы → облака → холмы → земля → объекты → трава.
- [x] Размещение: зоны для героя и кустарников, rejection sampling для деревьев.
- [x] Композиция: линия горизонта, «герой» по центру, тени под объектами.
- [x] Плотность: 5–7 дальних деревьев, 4 средних, бюджет до 8 тысяч полигонов.

### M6. Анимация и GIF

- [ ] Ветер как чистая функция `(model, t)`.
- [ ] Кадры по равномерной сетке времени.
- [ ] Свой GIF-энкодер: квантование, LZW, задержки, цикл.

### M7. Удобство

- [ ] Галерея вариантов, клавиша «ещё».
- [ ] Сид в URL, кнопка «поделиться».
- [ ] `prefers-reduced-motion`.
- [ ] Пресеты размеров экспорта.

### M8. Дальняя перспектива

- [ ] Второй стиль — пиксель-арт: низкое логическое разрешение, ограниченная палитра,
  апскейл целым множителем. Мир и сиды общие с иллюстрацией, отличается только
  профиль вывода.

Не обязательство, а направление: если к M7 интерес пропадёт, M8 просто не начнётся.

## Риски

| Риск | Что делаем |
|---|---|
| Painter's algorithm не тянет тысячи полигонов | бюджет ~2500 полигонов на сцену, замер `render()` в тесте, LOD для дальних планов |
| GIF получается тяжёлым | 64–128 цветов, дизеринг, 480×270, ≤ 48 кадров, бюджет 5 МБ |
| Все грибы «на одно лицо» | параметры-крайности (высокая тонкая ножка, плоская шляпка), а не только разброс вокруг среднего |
| Сцена выглядит как коллаж | общая палитра и общий источник света на всю сцену, воздушная перспектива |
| Названия нечитаемы | слоги с согласными на стыках, проверка на «три гласных подряд» |
